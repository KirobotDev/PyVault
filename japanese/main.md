# 📁 PyVault のアイデアへようこそ!

このファイルには、コントリビューターがプロジェクトを始めるための簡単なアイデアがいくつか含まれています。1 つのプルリクエストで 1 つ、2 つ、またはすべてを完了することができます!

> [!NOTE]
> これらのアイデアすべてについて、コードの作成や翻訳に AI を自由に使用できます。

### 💡 アイデア 1: タイプミスの修正と CLI プロンプトの英語への翻訳
現在、CLI プロンプトにはいくつかのタイプミスがあり、英語とフランス語が混在しています。プロジェクトの一貫性を保ち、誰にでもアクセスしやすくするため、すべてのプロンプトを正しい英語で書く必要があります。

**タスク:**

- [x] `input()` と `print()` 文のタイプミスを修正する。
- [x] 残っているフランス語のプロンプトを英語に翻訳する。

### 💡 アイデア 3: 起動時に既存のキーを自動読み込み
フォルダに `key.txt` がすでに存在する場合、キーを自動的に読み込むことでユーザー体験を向上させたいと考えています。

**タスク:**
- [x] アプリケーションの起動時またはコマンド実行時に `key.txt` が存在するか確認する。
- [x] 存在する場合はキーを読み込んで自動的に使用し、ユーザーが再度入力する必要をなくす。
- [x] 存在しない場合は現在の動作を維持する（入力を求めるか、生成を促す）。
- [x] コマンド（`add.py`、`decrypt.py`）を更新して、自動的に読み込まれたキーを使用するようにする。
