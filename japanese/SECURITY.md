# セキュリティポリシー

## サポートされているバージョン

PyVault は現在、初期開発段階にあります。現在のバージョンは実験的なプロトタイプであり、**本番利用を想定していません**。

> ⚠️ **PyVault を使用しないでください**

現在の暗号化システムはローカルに保存された Fernet キーに依存しており、堅牢なキー管理システムやマスターパスワードによる保護はまだ実装されていません。

| バージョン | サポート状況      |
|----------|------------------|
| 0.2.x    | ❌（実験的）      |
| < 0.2.0  | ❌               |

## 脆弱性の報告

PyVault 内でセキュリティ上の脆弱性を発見した場合、公の場で開示しないでください。

このプロジェクトは実験的な学習プロジェクトですが、責任ある開示の実践は歓迎されます。次に示す方法でセキュリティの脆弱性を報告できます。

1. リポジトリで GitHub セキュリティアドバイザリが有効になっている場合は、下書きのセキュリティアドバイザリを開く。
2. 作者の GitHub プロフィール（https://github.com/KirobotDev）から直接連絡する。

報告には次の情報を含めてください。
- 脆弱性の説明。
- 問題を再現する手順。
- （任意）可能な解決策や緩和策。

妥当な期間内に、脆弱性の受け取りを確認する応答が届きます。
